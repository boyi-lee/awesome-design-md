# Mockup Contract

Mockups are renderings of approved packaging, not a second design stage.

## Preconditions
Photoreal mockups require the appropriate locks:
- Artwork Lock
- Structure Lock
- Product Truth Lock

## Allowed transformations
- camera angle
- lighting
- shadow
- depth of field
- environment
- physically plausible film / paper / board reflections and wrinkles

## Forbidden transformations
- logo changes
- copy changes
- layout changes
- icon changes
- package structure changes
- transparent-window changes
- invented accessories or product parts
- invented claims / certifications

## Required outputs
When requested, produce separate files for:
- front hero shot
- back hero shot
- 3/4 structural shot
- scene shot

## Validation
A mockup is rejected if it is visually attractive but materially inconsistent with locked artwork or structure.
