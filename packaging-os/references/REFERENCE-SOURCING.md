# Reference / Inspiration Sourcing

## Goal
Find useful packaging references without copying layouts or treating inspiration as factual evidence.

## Search axes
Use at least two of these when design work is requested:
1. Same category — e.g. rainwear, travel accessories, convenience goods.
2. Same structure — e.g. transparent pouch, header card, folding carton.
3. Same channel — e.g. mass retail, drugstore, lifestyle store, ecommerce.
4. Cross-category principle — borrow hierarchy, typography, color logic, or transparency treatment from unrelated categories.

## For every reference, record
- source / URL
- category
- structure
- channel
- what is useful
- what must not be copied
- whether it affects structure, hierarchy, visual language, or mockup treatment

## Creative synthesis
References should be converted into 2–3 distinct creative directions, each with:
- concept sentence
- visual principle
- information hierarchy
- material / transparency treatment
- reason it fits the product
- risks / trade-offs

## Hard rules
- Inspiration cannot support factual claims.
- Do not copy a competitor's layout, illustration, or distinctive trade dress.
- Prefer extracting reusable principles over collecting many images.
- References that do not change a design decision should not be kept.
