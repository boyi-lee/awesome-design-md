# Resource Map

This map translates the curated design-resource repo into packaging tasks.

| Need | Resource class | Example use |
|---|---|---|
| Packaging references | Packaging galleries/editorial | category conventions, structure inspiration |
| Brand/visual references | Brand guidelines, visual journals | visual language and series behavior |
| Color | palette/accessibility tools | palette exploration and contrast checking |
| Typography | font/pairing resources | hierarchy and font pairing |
| Icons/illustration | icon libraries | consistent factual icon system |
| Mockup | mockup libraries/editors | shelf, front, series, hand-held preview |
| UI/agent design systems | DESIGN.md resources | AI-readable design-language patterns |

## Routing rule
Research output must state:
- resource used
- query/category searched
- reference selected
- design decision influenced
- what was **not** copied

References guide decisions; they are not licenses to clone another brand's trade dress.
