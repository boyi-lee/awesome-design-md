# Output Menu

已讀取產品資料。開始前請選擇這次需要的產出，可複選：

1. **商品資料整理** — 結構化產品資訊、Evidence、Assumption、Unknown、缺漏清單。
2. **包裝企劃** — 包裝定位、USP、資訊層級、設計方向與參考拆解。
3. **包裝文案** — 正背面文案、Feature / Benefit、說明與注意事項。
4. **包裝設計** — 正背面平面設計、視覺系統與 Artwork Preview。
5. **包裝結構 / 生產規格** — 依包裝類型輸出 Dieline、Bag Spec、Cutline 或其他工程規格。
6. **完整包裝開發** — 從 Intake 一路跑到 Design、Engineering、Mockup、Validation、Iteration 與 Release Gate。

若選擇 ⑤ 或 ⑥，缺少生產必要尺寸或印刷廠規格時，系統會先標示 `BLOCKED` 並列出待補資料，不會自行推算。
